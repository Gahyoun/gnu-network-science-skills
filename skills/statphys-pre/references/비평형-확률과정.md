# 비평형 확률과정 — master equation에서 요동정리까지

목차: 1. master equation · 2. Langevin/Fokker–Planck · 3. 생성함수·moment closure
· 4. 흡수상태 전이와 DP · 5. 비평형 정상상태와 요동정리 · 6. 자주 틀리는 지점

## 1. Master equation

    ∂_t P(n,t) = Σ_{n'} [ W(n'→n) P(n',t) − W(n→n') P(n,t) ]

- **detailed balance** W(n→n')P_eq(n) = W(n'→n)P_eq(n')가 성립하면 평형, 아니면 비평형
  정상상태(NESS)이고 정상상태에서도 확률흐름 J ≠ 0이 남는다. 이 구분을 논문 초반에
  명시하는 것이 PRE에서 기대되는 서술이다.
- **system-size expansion (van Kampen)**: n = Ωφ(t) + √Ω ξ로 두고 Ω로 전개하면
  O(Ω^{1/2})에서 결정론적 rate equation, O(Ω⁰)에서 선형 Fokker–Planck(가우시안 요동)가 나온다.
  요동 크기가 √Ω로 줄어드는 것이 "mean-field가 큰 계에서 좋아지는" 이유이고,
  임계점 근처에서 이 전개가 깨지는 것이 요동 지배 영역이다.
- **유한계의 소멸(extinction)**: 흡수상태가 있으면 진짜 정상상태는 흡수상태뿐이다.
  준정상상태(quasistationary) 분포와 평균 소멸시간 T_ext(활성상에서 보통 지수적으로
  큼, 임계에서 멱함수)를 구분해서 다룬다.

## 2. Langevin / Fokker–Planck

    ẋ = A(x) + √(2D(x)) η(t),  ⟨η(t)η(t')⟩ = δ(t−t')

- **Itô vs Stratonovich**: D가 x에 의존하면(multiplicative noise) 두 해석의 정상분포가
  다르다. Itô 규약의 Fokker–Planck는 ∂_t P = −∂_x(AP) + ∂_x²(DP),
  Stratonovich는 ∂_t P = −∂_x(AP) + ∂_x(√D ∂_x(√D P)). 수치적으로 Euler–Maruyama는 Itô,
  Heun/predictor–corrector는 Stratonovich에 수렴한다. **논문에 규약을 반드시 적는다.**
- **model A/B/C 분류(Hohenberg–Halperin)**: order parameter가 보존되지 않으면 model A
  (z ≈ 2.17 for 3D Ising), 보존되면 model B (z = 4 − η). 동역학 지수를 보고할 때
  어떤 동역학 class인지 밝히지 않으면 비교 자체가 성립하지 않는다.
- **장 이론 형태**: 임계 동역학은 ∂_t φ = −Γ δF/δφ + ζ로 쓰고, F = ∫[ (∇φ)²/2 + rφ²/2 + uφ⁴/4 ]
  (φ⁴ 이론)에서 RG를 돌린다. 이 형태로 쓰는 순간 어떤 universality class인지가 드러난다.

## 3. 생성함수와 moment closure

- pair approximation은 단일 노드 mean-field보다 임계점을 대개 크게 개선하지만,
  이질적 네트워크에서는 여전히 계통오차가 남는다. 어떤 닫힘(closure)을 썼는지와
  그 닫힘이 무시한 상관을 명시한다.
- percolation·branching process에는 확률생성함수 G₀(x) = Σ p_k x^k, G₁(x) = G₀'(x)/G₀'(1)이
  표준 도구다. 거대덩어리 조건 G₁'(1) = ⟨k(k−1)⟩/⟨k⟩ > 1 (Molloy–Reed κ > 2),
  무작위 제거 하 임계 잔존확률 φ_c = 1/(κ − 1).

## 4. 흡수상태 전이와 DP

- **Janssen–Grassberger 추측**: (i) 스칼라 order parameter, (ii) 유일한 흡수상태,
  (iii) 단거리 상호작용, (iv) 추가 대칭·보존량·quenched disorder 없음 →
  전이는 **directed percolation (DP)** class. 이 조건 중 무엇이 깨지는지 확인하는 것이
  "새 class"를 주장하기 전의 첫 관문이다.
- class를 바꾸는 대표 요인: 보존량 → Manna/C-DP class, 흡수상태 다수·패리티 보존 →
  PC(parity-conserving) class, 장거리 전파(Lévy) → 연속변화 지수, quenched disorder →
  Griffiths phase와 activated scaling(로그적 동역학).
- **동역학 임계 스케일링(seed 실험)**: 단일 활성 씨앗에서 출발해
  생존확률 P(t) ~ t^{−δ}, 평균 활성 수 N(t) ~ t^{θ}, 확산 R²(t) ~ t^{2/z}.
  정상상태 측정보다 임계점 결정에 민감해서 DP 여부 판정에 널리 쓰인다.
  일반화 hyperscaling: δ + θ = d/z − δ' 형태의 관계를 함께 확인한다.
- 네트워크 위의 흡수상태 전이는 유효 차원이 높아 대개 mean-field DP(β=1)로 가지만,
  이질성이 강하면 Griffiths 효과로 멱함수 영역이 넓어져 임계점 판정이 어려워진다.

## 5. 비평형 정상상태와 요동정리

- **Jarzynski**: ⟨e^{−βW}⟩ = e^{−βΔF} (비평형 일에서 평형 자유에너지를 얻음).
- **Crooks**: P_F(W)/P_R(−W) = e^{β(W−ΔF)}. 두 방향 분포의 교점이 ΔF.
- **엔트로피 생성 요동정리**: P(Σ)/P(−Σ) = e^{Σ/k_B} → ⟨Σ⟩ ≥ 0 (2법칙을 등식의 따름정리로 얻음).
- **thermodynamic uncertainty relation (Barato–Seifert 2015)**:
  Var(J)/⟨J⟩² ≥ 2k_B/Σ. 전류의 정밀도를 올리려면 소산을 지불해야 한다는 뜻으로,
  분자모터·화학반응망·정보엔진 논문에서 표준 벤치마크로 쓰인다.
- 확률열역학을 쓰는 원고에서는 **열/일/엔트로피의 정의를 궤적 수준에서** 먼저 적는다.
  정의를 생략한 채 요동정리를 인용하면 referee가 가장 먼저 되묻는 지점이다.

## 6. 자주 틀리는 지점

- rate equation(결정론)의 고정점을 곧바로 임계점이라 부르는 것 — 요동이 임계점을 옮긴다.
- 유한계 흡수상태 시뮬레이션에서 소멸한 표본을 포함해 평균 → 정상상태 밀도가 0으로 끌린다.
  QS 방법(de Oliveira–Dickman) 또는 생존 표본 평균을 쓴다.
- parallel update와 random-sequential update를 같은 모형으로 취급 — 동기 업데이트는
  추가 상관을 만들고 임계점이 다르며, 경우에 따라 class도 바뀐다.
- Gillespie 알고리즘의 시간 단위와 동기 업데이트의 "sweep"을 혼용해 z를 비교.
- multiplicative noise SDE에서 규약 미표기(§2).
- 요동정리를 정상상태가 아닌 과도상태 데이터에 적용하면서 초기분포 조건을 확인하지 않음.
