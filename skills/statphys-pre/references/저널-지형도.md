# 저널 지형도 — 범용에서 통계물리·복잡계 전문지까지

사용자(연구그룹)가 실제로 구독·추적하는 저널 목록을 근거로 한 venue-fit 지도.
기본 홈은 **Phys. Rev. E**이고, 결과의 성격에 따라 위아래로 이동한다.

**주의**: 저널의 범위·논문 유형·서식·정책은 바뀐다. 투고를 앞둔 구체 조언
(분량 제한, Letters 형식, 데이터 공개 요건)은 `web_search`로 현재 규정을 확인한 뒤 말한다.

## 0. 결과 유형 → 저널 1차 매핑

## 1. 통계물리·복잡계 core — 이 스킬의 홈

- **Phys. Rev. E** — 통계물리·비선형동역학·soft matter·생물물리·전산물리·네트워크.
  기술적 완결성과 정량적 엄밀성을 본다. 유도·크기 사다리·오차·collapse가 갖춰지면
  "넓은 관심"이 약해도 실린다. 반대로 그것들이 없으면 결과가 흥미로워도 통과하지 못한다.
- **Phys. Rev. Research** — 범위는 APS 전체, PRE보다 novelty 문턱이 낮고 오픈액세스.
  재현 연구, 음성 결과, 방법 비교처럼 PRE에서 "incremental"로 읽힐 수 있는 견실한 결과의
  자연스러운 집. APC가 있으므로 사용자에게 비용을 먼저 확인한다.
- **Journal of Physics: Complexity (IOP)** — 복잡계 전반, 네트워크 비중 높음. 오픈액세스.
  PRE보다 학제간 서술을 허용하고 물리 밖 독자를 상정한다.
- **PLOS Complex Systems** — 2024년 창간, 학제간 복잡계 전반(카오스·네트워크·리스크·
  시스템생물학·경제). 방법론적 엄밀성과 **재현성·데이터/코드 공개**를 명시적으로 요구하므로,
  시뮬레이션 코드와 파라미터를 공개할 준비가 된 원고에 적합하다.

## 2. 물리 광범위 — 위로 올릴 때

- **Phys. Rev. Lett.** — "왜 물리학자 일반이 알아야 하는가"에 한 문장으로 답할 수 있어야 한다.
  분량이 짧아 기술적 검증(크기 사다리·오차)은 Supplemental Material로 밀리는데,
  **밀린 검증이 부실하면 그대로 reject 사유**다. PRL 투고 시 PRE급 부록을 같이 준비한다.
- **Phys. Rev. X** — 선별성이 매우 높고 분량 제한이 느슨하다. 이론+수치+데이터가 하나의
  완결된 이야기를 이룰 때. 오픈액세스 비용 확인 필요.
- **Nature Physics** — 물리학 내 넓은 관심 + 개념적 전환. 편집자 단계 desk reject 비율이 높다.
- **Communications Physics** — Nature Portfolio 오픈액세스. Nature Physics에서 범위가
  좁다고 판단된 결과의 흔한 착지점.

## 3. 범용 최상위 — 드물게

- **Nature / Science / PNAS / Science Advances / Nature Communications** —
  복잡계 논문이 여기 실리는 경우는 대개 (i) 대규모 실데이터로 사회·역학·도시 현상에
  대해 정책적 함의가 있거나, (ii) 이론이 실험/관측과 정량적으로 맞물릴 때다.
  순수 모형의 임계지수는 여기 맞지 않는다 — PRE로 보낸다.
- **Nature Human Behaviour** — 인간 행동·사회 동역학의 실증. 물리 모형이 주인공이면 부적합.
- **Nature Computational Science** — 계산 방법론 자체가 기여일 때.

## 4. 데이터·응용·리뷰

- **EPJ Data Science** — 실데이터 기반 복잡계(이동성·소셜·도시). 데이터 출처·표집 편향
  서술이 심사의 중심이다.
- **Applied Network Science** — 응용 사례 중심, 오픈액세스. 이론적 novelty 요구가 낮다.
- **PLOS Comput. Biol.** — 생물학적 질문이 주도할 때. 물리적 보편성만으로는 약하다.
- **Scientific Data** — Data Descriptor 전용. 분석이 아니라 데이터·메타데이터 품질을 심사한다.
- **Rev. Mod. Phys.** — 초청/제안 기반 종합 리뷰. 문헌 조사 결과를 정리할 때의 **참고 기준**이지
  일반 투고 대상이 아니다.

## 5. 동향 추적

- **Mason Porter의 블로그(Quantum Chaotic Thoughts)** 같은 커뮤니티 소스는 저널이 아니라
  화제·논쟁의 조기 신호로 쓴다. 인용 근거로는 쓰지 않는다.

## 6. 저널 선택을 사용자와 정리하는 방식

1. 결과를 한 문장으로 쓰게 한다("우리는 X에서 Y임을 보인다").
2. 그 문장이 **물리학 일반**에 대한 것인지, **복잡계 커뮤니티**에 대한 것인지,
   **특정 응용 분야**에 대한 것인지 가른다 → §0 표.
3. 검증의 깊이를 확인한다. 깊으면 PRE/PRX, 짧고 강렬하면 PRL(단 부록 필수).
4. 오픈액세스 비용·기관 지원 여부를 먼저 묻는다. PRX·PR Research·IOP·PLOS·Nature Portfolio는
   APC가 있고, PRE는 구독형 선택이 가능하다(현재 정책은 확인할 것).
5. 1순위에서 desk reject되면 어디로 갈지 **미리** 정해 둔다. 서식 재작업 비용이 작은
   경로(APS 내부 이동: PRL → PRE / PR Research)를 우선 고려한다.
