# 수치방법 — Monte Carlo, 오차, 유한크기 스케일링 실행 절차

목차: 1. 알고리즘 선택 · 2. 평형화와 자기상관 · 3. 오차 산정 · 4. FSS 실행 절차
· 5. 네트워크·연속시간 동역학 · 6. 재현성 체크리스트 · 7. 성능

## 1. 알고리즘 선택

| 상황 | 권장 | 비고 |
| --- | --- | --- |
| 평형 스핀계, 임계점에서 멀리 | Metropolis / heat-bath | 단순, z ≈ 2.17 (3D Ising model A) |
| 평형 스핀계, 임계점 근처 | Wolff (단일 클러스터) | P_add = 1 − e^{−2βJ}, 2D Ising에서 z ≈ 0.25 |
| 전체 배열 갱신이 필요 | Swendsen–Wang | 클러스터 분포 자체가 관측량일 때 |
| 거친 에너지 지형·spin glass | parallel tempering (replica exchange) | 온도 사다리 수용률 ~20–30%로 조율 |
| 자유에너지·희귀사건 | Wang–Landau, umbrella sampling | 1차 전이의 장벽 측정에 필수 |
| 연속시간 확률과정 | Gillespie SSA (정확) | 사건 기반, 시간 단위가 물리적 |
| 대규모 네트워크 SIS/SIR | 최적화 Gillespie / rejection-based | 나이브 SSA는 O(N) 갱신으로 느려짐 |
| 흡수상태 근처 정상상태 | quasistationary (de Oliveira–Dickman) | 소멸 시 과거 활성 배열로 복원 |
| SDE | Euler–Maruyama (Itô, 강수렴 0.5) / Heun (Stratonovich) | 규약 명시, dt 수렴 검사 필수 |

critical slowing down을 무시한 Metropolis 결과는 임계점 근처에서 통계가 사실상 없는 것과
같다. 알고리즘을 바꿀 수 없으면 최소한 τ_int ~ L^z를 재서 실행 길이를 L에 따라 늘린다.

## 2. 평형화와 자기상관

1. 관측량 시계열을 먼저 **그려본다**. 초반 표류 구간을 눈으로 확인하고 버린다
   (보통 전체의 10–20%, 또는 τ_int의 20배 이상).
2. 서로 다른 초기조건(질서/무질서)에서 출발한 두 실행이 같은 값으로 수렴하는지 확인한다.
   1차 전이 근처에서는 이 검사를 반드시 해야 한다.
3. `sp_int_autocorr(x)`로 τ_int를 잰다. 정의는 τ_int = 1/2 + Σ_{t≥1} ρ(t)이고,
   Sokal 자동 윈도우(W ≥ c·τ_int, c ≈ 6)로 잘라 잡음 누적을 막는다.
4. 유효 표본수 N_eff = N/(2 τ_int). N_eff가 수백 미만이면 오차 추정 자체가 불안정하다 —
   실행을 늘리거나 독립 시드를 더 쓴다.

## 3. 오차 산정

- **선형 평균**: `sp_mc_error(x)` → err = √(2 τ_int Var(x)/N).
- **비선형 함수**(χ = N(⟨m²⟩−⟨m⟩²)/T, Binder U₄, 지수 비 등): `sp_jackknife(x, func, nblocks)`.
  블록 크기는 2τ_int보다 충분히 커야 한다(보통 nblocks 20–50).
- **지수·임계점의 오차**: 곡선 피팅 공분산이 아니라 **독립 실행에 대한 bootstrap**으로 낸다.
  실행 단위(시드 단위)로 재표집해 전체 분석 파이프라인을 반복하고, 그 분포의 표준편차를
  오차로 보고한다. 상관된 데이터에 `curve_fit`을 돌린 표준오차는 통상 크게 과소평가된다.
- **systematic error**를 따로 적는다: 피팅 구간(L_min) 선택, correction-to-scaling 무시,
  임계점 추정의 불확실성이 지수로 전파되는 양. PRE 원고에서는 통계오차와 계통오차를
  구분해 쓰는 것이 기대된다.

## 4. FSS 실행 절차 (그대로 따라 할 것)

1. 크기 사다리를 정한다. 최소 4개, 가급적 기하급수(L = 16, 32, 64, 128). 작은 L은
   correction-to-scaling 때문에 빼야 할 수도 있으므로 L_min 민감도를 나중에 확인한다.
2. 각 L에서 온도(또는 제어변수) 격자를 임계점 추정치 주변에 촘촘히 깐다.
   necessary: 격자 간격 ≪ 예상 임계창 폭 ~ L^{−1/ν}.
3. 평형화·τ_int(§2) → 각 점에서 ⟨m⟩, ⟨m²⟩, ⟨m⁴⟩, 에너지 모멘트를 저장한다.
   **원시 시계열 또는 블록 평균을 보관**한다(나중 bootstrap에 필요).
4. `sp_binder(m)` + jackknife로 U₄(T, L)를 만들고 교차점에서 T_c를 1차 추정.
   교차점이 L에 따라 표류하면 T_c(L) = T_c + a L^{−(1/ν+ω)}로 외삽한다.
5. 로그–로그 기울기로 β/ν(m at T_c), γ/ν(χ_max)를 얻는다. dU₄/dT|_{T_c} ~ L^{1/ν}로 ν를 따로 잡는다.
6. `sp_fit_collapse(sizes, xs, ys, dys, p0)`로 (T_c, ν, ζ)를 동시 추정하고 품질 S를 본다.
   S가 1 근처면 오차 수준에서 collapse 성립, 크게 크면 correction-to-scaling 항
   (1 + b L^{−ω})을 넣거나 작은 L을 버린다.
7. bootstrap으로 (T_c, ν, β, γ)의 오차를 내고, scaling relation과 hyperscaling을
   **자기 값으로** 검사한다. 그림에는 반드시 collapse 전/후를 함께 싣는다.

1차 전이가 의심되면 순서가 다르다: 에너지·order parameter의 **분포**를 먼저 보고
(이중봉 여부), Binder minimum U_min(L)의 수렴, χ_max ~ L^d를 확인한 뒤 지수 논의로 간다.

## 5. 네트워크·연속시간 동역학

- 네트워크에서는 L 대신 N, 지수는 ν̄ = νd. 그림의 가로축은 (λ − λ_c) N^{1/ν̄}.
- **앙상블 평균의 층위**를 구분한다: (i) 같은 네트워크 위 동역학 실현, (ii) 네트워크 실현.
  둘 다 평균하되 각각의 분산을 따로 보고한다.
- 흡수상태 계는 QS 방법. 구현: 소멸이 발생하면 과거에 저장해 둔 활성 배열 중 하나를
  무작위로 복원하고, 그 배열 저장소를 일정 확률로 갱신한다.
- **χ의 정의를 캡션에 적는다.** 격자 스핀계의 유한계 관례는 χ = N(⟨m²⟩ − ⟨|m|⟩²)/T이고,
  ⟨m⟩을 쓰는 정의는 T < T_c에서 다른 값을 준다. 어느 쪽을 썼는지 밝히지 않으면 지수 비교가
  성립하지 않는다.
- susceptibility는 네트워크 동역학에서 χ = N(⟨ρ²⟩ − ⟨ρ⟩²)/⟨ρ⟩ 형태를 쓰는 관례가 있다
  (Ferreira et al. 2012) — 어느 정의를 썼는지 캡션에 적는다.
- Gillespie와 동기 업데이트의 시간 단위를 섞지 않는다. 비교가 필요하면 한쪽을
  다른 쪽 단위로 환산한 근거를 적는다.

## 7. 성능

- 핫루프는 `numba.njit`. 스핀계는 배열 대신 이웃 인덱스를 미리 펼쳐 두면 캐시 효율이 크다.
- 큰 네트워크는 CSR 인접(`scipy.sparse`)과 이웃 리스트(`indptr`, `indices`) 직접 접근.
- λ_max는 `scipy.sparse.linalg.eigsh(A, k=1, which='LA')`.
- 병렬 실행은 독립 시드로 나누고(`SeedSequence.spawn`), 실행 단위 결과를 따로 저장해
  나중에 bootstrap할 수 있게 한다. 평균만 저장하면 오차를 다시 낼 수 없다.
- 규모가 커지면 로컬 대신 원격 compute로 보내는 것을 고려한다(`list_compute`로 확인).
