# 관련내용 개념 네트워크

2026-10-05에 원본 목차의 566쪽을 읽어 ‘관련내용’ 표시(`headword.gif`)가 있는 문단의 링크만 수집했다. 최종 수집에서는 시간초과 항목이 없었다. 821개 관련내용 문단에서 2,180개 개념과 중복을 합친 5,844개 방향 연결을 구성했다. 개념명과 링크, 원본 페이지의 SHA-256만 보관하며 원문 문장·그림·프로그램은 복제하지 않는다.

## 연결의 의미

A → B는 **A의 관련내용에 B가 언급됨**을 나타낸다. 원본에서 해당 문단 앞의 마지막 이름 앵커(`a[name]`)를 A로, 링크 표시문을 B로 읽었다. 이 화살표로 선행학습 관계나 인과관계를 단정하지 않는다. 일반 본문 링크, 목차 링크, 그림의 ‘크게보기’는 간선에 포함하지 않는다.

개념명은 NFC와 연속 공백을 정규화한 뒤 동일 표시문끼리 합친다. 한 표시문에 여러 원본 위치가 있으면 `sources`에 모두 보관한다. 같은 위치를 가리키는 서로 다른 별칭은 각각의 단어 노드로 남긴다. 이름이 같은 다른 의미의 개념은 현재 합쳐질 수 있어, 의미 구분이 필요한 분석은 `sources`를 함께 검토해야 한다. 원본 표제어도 포함하므로 관련내용 연결이 없는 고립 노드가 있다.

자기 연결은 제외한다. 같은 A → B의 여러 언급은 한 간선의 `mentions`로 보관한다. 분석은 언급 빈도의 가중치 없이 수행한다. 연결은 소스 앵커와 대상 주소로 추적할 수 있다. `src/related-links.json`이 수집 정본, `assets/network.json`이 브라우저용 데이터다.

## GUI와 분석

- 전체 또는 중심 개념(ego) 보기, 들어오는/나가는/양방향 탐색, 1·2단계 거리와 대단원 필터.
- ego 노드는 선택한 방향으로 BFS하여 찾고, 그 노드 사이의 모든 방향 간선을 표시한다. 대단원 필터는 이 범위에 추가 적용된다.
- 노드 끌기, 화면 이동, 휠·버튼·두 손가락 확대/축소, 화면 맞춤. 개념 목록과 분석 표에서도 키보드로 선택할 수 있다.
- 현재 부분그래프의 노드·간선 수, in/out degree, 밀도 `m / [n(n−1)]`, 상호 연결 간선 수/m, 약연결 성분 수.
- PageRank는 전체 그래프에서 damping=0.85, dangling 확률 균등 분배, 최대 100회 또는 L1 변화량 1e-10 미만으로 계산한다. 표는 전체 PageRank 상위 50개를 현재 범위에서 표시한다.
- 현재 노드·간선 및 탐색 조건을 JSON으로 저장하여 다른 분석 도구에서 읽을 수 있다. 중심·보기·방향·거리·대단원은 URL에 저장한다.

전체 그림은 많은 연결이 겹칠 수 있다. 개념 선택과 중심 관계 보기로 세부 연결을 살펴본다. 배치 거리와 노드 위치는 가독성을 위한 레이아웃이며 물리량이나 개념 유사도의 수치가 아니다. 노드 크기는 전체 연결 수를 반영한다. 대단원은 색상·모양·이름을 함께 사용한다.

외부 그래프 라이브러리·외부 API 서버 없이 작동한다. 그래프 데이터는 네트워크/개념 안내 화면에서만 읽는다. 작은 ego 네트워크는 거리에 따른 동심원으로 배치한다. 큰 그래프는 공간 격자로 근처 노드의 반발력을 계산하며 100프레임 후 정지한다. 고밀도 전체 그래프에서는 선택한 연결에 화살표를 강조하고 확대할 때 나머지 화살표를 표시한다.

## 갱신

`python3 tools/collect-related.py`로 원본 링크 메타데이터를 갱신한 뒤 `node tools/build.mjs`를 실행한다. 빌드는 원본 사이트에 접속하지 않는다. 한글이 새로 생기면 서체를 다시 축소한다. 수집 오류와 최종 수치 기록은 `docs/network-report.json`에 남긴다.
