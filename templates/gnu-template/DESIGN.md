# GNU template — 경상국립대학교 학교테마

버전 1.0 · 자료 확인일 2026-10-04 · 교내 구성원용 비공식 제작 보조 자료

이 문서는 A4 홍보문·세미나 안내문, 학술포스터, HTML 프레젠테이션과 웹페이지를 생성할 때 사용하는 디자인 프롬프트다. KRDS의 탐색·입력·접근성 원칙을 바탕으로 경상국립대학교 웹사이트와 VI의 시각 요소를 적용한다. 아래 수치 중 ‘제안’으로 표시한 값은 이 도구의 제작 기준이며 학교의 공식 규정이 아니다.

## 1. 작업 범위와 적용 순서

사용자가 지정한 콘텐츠·매체·기존 페이지 구조를 먼저 확인한다. 실제 로고와 공식 모티프는 공식 원본을 선택하고, 표·메뉴·본문의 구조에는 KRDS를 참고한다. 웹사이트 관찰값은 시각적 연속성을 위한 참고값이다. 접근성을 해치는 동작까지 복제하지 않는다.

1. 사용자의 작업 조건과 실제 콘텐츠를 따른다.
2. 공식 브랜드 자산은 해당 VI의 비례·색상·사용 규정을 지킨다.
3. KRDS의 의미 있는 HTML 구조, 탐색, 입력, 오류 안내 원칙을 적용한다.
4. 웹은 대학의 정보 안내 페이지, 포스터는 학술 발표물의 관례를 따른다.
5. 미정의 사항에는 이 문서의 제안값을 사용한다.

원문에 없는 연구 결과·수치·교수 이름·일정·소속·후원기관은 만들어 넣지 않는다. 필요한 정보가 없으면 편집 가능한 빈 항목으로 남기고 작업 설명에서 알린다. 실제 콘텐츠가 적으면 섹션도 줄인다.

## 2. 문구와 표현

- 페이지 상단은 실제 페이지명, 연구 제목, 행사명으로 시작한다. 두괄식 후크 메시지나 광고성 헤드라인을 추가하지 않는다.
- ‘미래를 바꾸는 연구’, ‘새로운 가능성의 시작’, ‘지금 경험하세요’ 등의 소개 카피를 자동으로 만들지 않는다. 이미 제공된 정식 제목·공식 슬로건·연구 결론은 임의로 바꾸지 않는다.
- 연구 목적·방법·결과는 해당 본문 위치에서 서술한다. 논문의 초록이나 결과 요약을 금지하는 규칙으로 확대해석하지 않는다.
- 기관 안내문은 ‘일정’, ‘신청 방법’, ‘자료 내려받기’, ‘문의’처럼 기능을 드러내는 표제를 쓴다. 독자를 설득하는 수사보다 확인 가능한 정보를 적는다.
- 본문은 짧은 문단, 실제 항목 목록, 표로 구성한다. 한 문장마다 굵게 표시하거나 모든 문단에 아이콘을 붙이지 않는다.
- 미니 영문 상단 라벨, 장식용 대문자 슬로건, 이모지, 과도한 느낌표를 넣지 않는다. 영어 연구 제목·학술 용어·소속 표기는 필요에 따라 유지한다.

## 3. 형태와 조형 요소

흰 바탕, 검정에 가까운 본문, 명확한 좌측 정렬, 얇은 회색 구분선, 직사각형 메뉴와 표를 기본으로 한다. 제목·본문·그림의 기준선을 맞추고 여백으로 내용을 구분한다.

### 사용하지 않는 표현

- 말풍선·대화 버블, 떠다니는 구체·블롭, 장식용 원형 배경.
- 알약 모양 탭·태그·버튼의 반복, 큰 모서리 반경의 카드가 화면을 채우는 구성.
- 근거 없이 만든 ‘특징 3개’ 카드, 벤토 그리드, 카드마다 다른 파스텔 배경.
- 보라색·분홍색 네온 그라데이션, 유리 효과, 과한 그림자·블러·입체 장식.
- 문단을 가리는 캐릭터 챗봇, 자동 캐러셀, 스크롤 진입 애니메이션.
- 허구의 연구 지표·성과 카운터·후기·파트너 로고 행.

차트의 데이터 점, 라디오 버튼, 기능상 필요한 아이콘까지 ‘버블’로 취급하지 않는다. 논리 구조를 설명하는 학술 도식은 허용한다. 다만 장식용 연결선이나 큰 원형 노드를 기본 레이아웃으로 사용하지 않는다.

### 조형 요소의 적용

학교 원본 그래픽 모티프를 사용하려면 제공된 도안을 선택한다. 심벌을 새로 그려 패턴으로 만들거나 로고의 일부를 떼어 임의 조형물로 만들지 않는다. 일반 안내 페이지에서는 별도 모티프 없이 제목, 구분선, 표만으로 구성해도 된다.

공식 웹 CSS에서 확인한 청색 그라데이션 `#009EDB → #0071DB`는 필요할 때 작은 구분 띠에만 적용한다. 글자가 올라가는 탭·버튼은 아래의 대비 확보용 단색을 기본으로 한다. 이는 이 도구의 접근성 보완 제안이다.

## 4. 색상

### 공식 VI에서 확인한 값

출처: [대학 VI 기본요소](https://www.gnu.ac.kr/main/cm/cntnts/cntntsView.do?cntntsId=1198&mi=1369)의 BS13 전용색상 견본. RGB와 CMYK는 매체별 원본 값이며 서로 자동 변환한 값이 아니다.

| 이름 | RGB / 웹 표기 | 인쇄 견본 | 쓰임 |
|---|---|---|---|
| GNU Blue | 0, 158, 219 · `#009EDB` | PANTONE 2192 C · C80 M20 | 공식 원본, 작은 강조선·표식 |
| GNU Grey | 67, 82, 90 · `#43525A` | PANTONE Coolgray 11 C · C20 K80 | 공식 원본·보조 색상 |
| Silver | 188, 190, 192 · `#BCBEC0` | PANTONE 877 C · K30 | 필요할 때만 쓰는 부수 색상 |
| Gold | 179, 161, 119 · `#B3A177` | PANTONE 871 C · M10 Y40 K35 | 필요할 때만 쓰는 부수 색상 |

CMYK에서 생략된 채널은 0이다. 금·은 별색의 실제 인쇄 효과를 RGB 미리보기로 판단하지 않는다. 로고의 색은 원본 그대로 유지한다.

정부 청색을 대학의 공식 브랜드색으로 표기하지 않는다. KRDS는 기능과 접근성의 참고 기준이며, 학교 VI는 로고·모티프의 기준이다.

## 5. 서체

학교 웹사이트의 CSS와 인쇄 VI 지정서체는 구분해서 적용한다.

| 매체·영역 | 확인한 기준 | 이 도구의 적용 |
|---|---|---|
| 대학 웹 본문 | CSS 별칭 `NotoSans`; Noto Sans KR 파일 연결 | Noto Sans KR, 본문 400 |
| 대학 웹 메뉴·페이지 제목 | `SUITE` | 로컬 제공 시 SUITE 700–800 |
| 국문 VI 지정서체 | Noto Sans KR | 국문 포스터 본문·제목 |
| 영문 VI 지정서체 | SUIT | 영문 제목·소속에 선택 적용 |
| KRDS | Pretendard GOV | KRDS 중심의 서비스 화면을 요청했을 때 선택 |

SUIT와 SUITE는 서로 다른 서체다. 임의로 같은 이름처럼 표기하지 않는다. 로고의 학교명은 일반 텍스트로 다시 조판하지 않고 공식 조합 원본을 사용한다.

폰트 파일은 이 패키지에 포함되어 있지 않다. 대상 환경에 없으면 읽을 수 있는 시스템 산세리프로 대체하고 대체 사실을 작업 설명에 적는다. 다른 PC에서 사용할 인쇄물은 폰트 임베딩과 이용 조건을 확인한다. 외부 폰트 CDN에 접속해야만 읽히는 결과물을 기본으로 만들지 않는다.

### 웹 크기 제안

| 영역 | 데스크톱 | 모바일 | 굵기 |
|---|---|---|---|
| 페이지 제목 | 33px | 28px | 800 또는 700 |
| 대제목 | 24px | 22px | 700 |
| 소제목 | 20px | 19px | 700 |
| 본문 | 17px | 17px | 400 |
| 표·메타정보 | 15–16px | 15–16px | 400 |

33px 제목은 학교 CSS의 `1.65rem × 20px` 관찰값이다. 본문 17px는 KRDS 토큰을 참고한 제안이다. 본문 행간 1.65, 제목 행간 1.3, 자간 0을 기본으로 한다. 한글 제목은 단어 단위로 줄바꿈하되 긴 URL·DOI는 넘치지 않게 줄바꿈한다.

## 6. 웹페이지 구성

대학의 하위 정보 안내 페이지를 기본형으로 삼는다.

```text
운영 주체·기관 식별  |  실제 메뉴  |  필요한 경우 검색
──────────────────────────────────────────────
현재 위치
실제 페이지 제목                       필요한 페이지 도구
직사각형 하위 메뉴 또는 선으로 구분한 탭

본문 소제목
문단 / 일정표 / 자료 목록 / 입력 양식

다음 소제목
관련 내용 / 참고 자료 / 문의
──────────────────────────────────────────────
실제 운영 부서 · 연락처 · 갱신일
```

- 공식 대학 홈페이지 CSS의 컨테이너 관찰값은 1565px다. 작은 교내 도구에서는 최대 1200px, 좌우 여백 24px를 제안값으로 사용한다. 참고 페이지 재현 요청이면 관찰 폭을 적용할 수 있다.
- 모바일 여백은 16px. 1024px 이하에서는 메뉴를 축약하고, 768px 이하에서는 다단 본문을 한 단으로 바꾸는 것을 기본 제안으로 삼는다. 내용에 따라 조정한다.
- 제목 아래 여백 32px, 본문 섹션 사이 40–48px, 문단 사이 12–16px를 제안한다.
- 하위 메뉴는 직사각형으로 만들고 선택 상태는 텍스트와 테두리·밑줄 또는 단색 채움으로 표시한다. 패널 전환은 `button`, 페이지 이동은 `a`를 쓴다.
- 목록·자료실은 행과 구분선을 사용한다. 비교 데이터는 표, 절차는 번호 목록으로 제시한다. 모든 내용을 카드에 넣지 않는다.
- 버튼·입력의 모서리 반경은 2–4px, 높이는 기본 44px 이상을 제안한다. 패널은 0–2px, 그림자는 기본적으로 사용하지 않는다.
- 검색, 공유, 언어 선택, 로그인, 인쇄 등은 실제 기능이 있을 때만 표시한다. 동작하지 않는 버튼을 장식으로 붙이지 않는다.
- 소규모 연구실·학술 행사 페이지에는 대학 전체 메뉴를 그대로 복제하지 않고 해당 페이지의 실제 운영 주체와 메뉴를 표시한다.

### 접근성과 동작

본문 바로가기, 의미 있는 제목 단계, 키보드 조작, 보이는 포커스, 입력 라벨과 오류 메시지를 제공한다. 일반 텍스트의 색대비 목표는 4.5:1, 큰 글자와 UI 식별 요소는 3:1이다. 200% 확대와 320px 폭에서 본문이 잘리거나 겹치지 않는지 확인한다. 표 자체의 가로 스크롤은 설명·키보드 접근을 제공하고 페이지 전체가 가로로 밀리지 않게 한다.

탭은 선택 상태와 키보드 동작을 구현하고, 접힘 영역은 `aria-expanded` 상태를 유지한다. 장식 이미지는 빈 대체텍스트, 의미 있는 그림은 적절한 설명을 쓴다. 로고가 유일한 홈 링크 내용이면 링크 목적을 식별할 수 있게 한다. 모션은 필요한 상호작용에 한정한다.

## 7. 학술포스터 구성

포스터에는 웹 메뉴·검색창·버튼·빵부스러기 경로를 넣지 않는다. 기관 표시는 상단의 공식 로고와 실제 소속으로 하고, 연구 제목·저자·본문 그림이 우선 보이도록 한다.

- 학회 지정 규격이 있으면 그 규격을 따른다. 규격이 없으면 A0 세로 841 × 1189mm를 작업 기본값으로 제안한다.
- A0 기준 바깥 여백 25–30mm, 단 사이 12–18mm, 본문 2단을 기본으로 제안한다. 내용에 따라 3단 또는 일부 단 병합을 사용한다.
- 제목 64–84pt, 저자·소속 28–34pt, 섹션 제목 30–36pt, 본문 24–28pt, 캡션 20–24pt를 출발점으로 삼는다. 내용이 넘치면 글자부터 줄이지 말고 내용을 편집한다.
- 제목 띠는 흰색 또는 옅은 회색 바탕과 청색 구분선을 기본으로 한다. 대형 색면·그라데이션·광고형 캐치프레이즈는 추가하지 않는다.
- 본문 순서는 연구에 맞춰 배경·연구 질문, 방법, 결과, 논의·한계, 참고문헌·연락처를 조정한다. 모든 포스터를 동일한 섹션 수로 강제하지 않는다.
- 결과 그림을 충분히 크게 배치한다. 축 이름, 단위, 범례, 표본 수·오차 정의가 필요한 경우 확인하고 적는다. 제공되지 않은 통계량은 생성하지 않는다.
- 실제 수식·도식·그래프는 편집 가능한 벡터와 선명한 글자로 제작한다. 논문 그림을 캐릭터 일러스트로 대체하지 않는다.
- 지누와 캐릭터는 사용하지 않는다. 학교 로고와 필요한 공식 모티프만 선택한다.
- 로고·모티프의 최소 크기와 보호 공간은 해당 공식 도안을 따른다. 이 문서의 일반 여백 수치를 공식 보호 공간으로 주장하지 않는다.
- 인쇄 PDF는 최종 실물 크기, 폰트 임베딩, 벡터 선명도, 잘림을 확인한다. 래스터 사진은 실제 배치 크기에서 150–300ppi를 제안한다. 인쇄소 프로파일을 확인한 뒤 색 변환을 하고 CMYK 변환을 학교 공식색의 재정의로 취급하지 않는다.

## 8. 공식 로고와 모티프

`assets/official/`에는 로고·VI·모티프 Illustrator 원본과 PDF·이미지가 있다. 파일별 출처·SHA-256은 `assets/manifest.json`, 도안별 용도는 `assets/catalog.md`에 기록했다. 지누와 캐릭터는 제외한다.

AI·PDF·PNG·JPG가 도안 시트인지 단일 자산인지 확인하고 필요한 완성 도안 하나만 선택한다. 원본을 보존하고 사본으로 출력한다. 생성형 모델로 로고를 다시 그리거나 비례·색·글자 간격을 바꾸지 않는다. 색상활용, 모티프C, 장미·철쭉 응용은 `references/brand-variants.md`를 따른다. 학교 자산에 대한 권리와 사용 조건은 원 권리자에게 있다.

### A4 홍보문·세미나 안내문

A4 세로 210 × 297mm, 바깥 여백 12mm, 얇은 청색 테두리, 단색 제목 띠, 흰 본문, 하단 기관 표시를 기본으로 제안한다. 실제 제목을 상단에 놓고 일시·장소·연사·참여 방법을 본문에 적는다. 제공된 초록은 본문 문단으로 배치한다. 사진·QR은 실제 원본이나 주소를 받았을 때만 넣는다.

제목 26–30pt, 항목 14–16pt, 초록 본문 12–14pt를 출발점으로 삼는다. 내용이 늘면 여백·문단을 조정하거나 두 쪽으로 나누고 본문을 읽기 어려운 크기로 줄이지 않는다. 예시 파일의 입력 항목은 실제 콘텐츠로 바꾼 뒤 배포한다.

### HTML 프레젠테이션

16:9 슬라이드, 흰 바탕, 청색 선, 실제 발표 제목·저자·소속을 기본으로 한다. 표지는 공식 로고와 청색 테두리를 사용할 수 있다. GNU 심벌의 획을 늘려 프레임을 새로 만들지 않는다. 본문에는 슬라이드의 주제를 제목으로 쓰고 그림·수식·설명에 맞춰 한 단 또는 두 단을 선택한다. 알약·카드·버블·홍보 후크를 추가하지 않는다.

기본 템플릿은 표지, 배경, 방법, 결과, 논의의 5개 레이아웃 예시다. 실제 발표에 필요한 슬라이드 수와 순서로 조정한다. 연구 데이터를 템플릿 채우기용으로 만들어 넣지 않는다.

### 기본 저장 형식

항상 편집 가능한 HTML, 같은 내용의 PDF, PNG를 기본 결과로 준비한다. 슬라이드는 하나의 다쪽 PDF와 페이지별 PNG, 웹페이지는 전체 화면 PNG와 읽기용 PDF를 제공한다. 추가 PPTX·SVG는 사용자가 요청한 경우 제공한다.

PDF는 CSS의 실제 인쇄 크기와 페이지 구분을 따른다. PNG 기본값은 화면 미리보기용 96dpi이며 `--scale=2` 등으로 해상도를 높일 수 있다. 큰 포스터의 인쇄본은 벡터 PDF를 권장한다. HTML 폰트·이미지를 기다린 뒤 출력하고, PDF 규격·페이지 수, PNG의 잘림을 확인한다. 내보내기 실패는 사실대로 보고하고 HTML을 보존한다.

## 9. 결과물 확인

작업 후 다음 항목을 확인하고 실제 확인 범위만 보고한다.

- 실제 제목과 콘텐츠가 첫 화면에 있고 자동 생성한 후크 문구가 없는가.
- 말풍선·블롭·둥근 카드의 반복 없이 정보 구조가 드러나는가.
- 기관명·소속·연구 결과·일정에 허구의 내용이 없는가.
- 학교 공식색, 웹 관찰값, UI 제안값을 혼동하지 않았는가.
- 로고·모티프가 선택한 원본과 같고 도안 시트 전체를 잘못 배치하지 않았는가.
- 웹에서는 좁은 화면·확대·키보드·상태 표시·색대비를 확인했는가.
- 포스터에서는 실물 크기·서체·그림·잘림을 확인했는가.
