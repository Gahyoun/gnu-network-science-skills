# GNU template — 경상국립대학교 학교테마 디자인 지침

버전 2.0 · 자료 확인일 2026-10-04 · 교내 구성원의 학술·공익 목적 제작을 돕는 비공식 자료

A4 홍보문·세미나 안내문, 학술포스터, HTML 발표자료, 간단한 웹페이지를 만들 때 AI에게 함께 주는 지침이다. 화면 구조와 접근성은 KRDS(대한민국 정부 디자인 시스템)를, 로고·색·서체는 대학 VI와 대학 홈페이지를 따른다. 수치 옆의 표시는 출처의 종류다.

- **공식**: 대학 VI 자료에 적힌 값.
- **관찰**: 대학 홈페이지 CSS나 공식 서식 파일에서 읽은 값.
- **제안**: 이 도구가 정한 작업 기준. 학교나 KRDS의 규정이 아니다.

## 1. 판단 순서

1. 사용자가 준 내용, 매체 규격, 기존 프로젝트 구조.
2. 대학 VI 원본 도안(로고·모티프·캐릭터)의 비례와 색.
3. KRDS의 구조·탐색·접근성 원칙.
4. 대학 홈페이지와 학과 기존 안내물의 시각 양식.
5. 이 문서의 제안값.

원문에 없는 연구 결과, 수치, 인명, 일정, 소속, 후원기관, 연락처는 만들지 않는다. 빠진 정보는 `[입력 항목]`으로 남기고 작업 보고에서 알린다. 내용이 적으면 칸을 줄이고 여백을 둔다. 빈자리를 지어낸 문장으로 채우지 않는다.

## 2. 쓰지 않는 표현

학교 홈페이지와 학과 안내문은 제목, 항목, 표, 선으로 정보를 나열한다. 아래 표현은 그 양식에서 벗어나고 자동 생성물처럼 보이게 하므로 쓰지 않는다.

**문구**

- 두괄식 후크 메시지와 광고형 헤드라인. 첫 줄은 실제 행사명·연구 제목·페이지명이다.
- ‘미래를 여는’, ‘새로운 가능성’, ‘지금 바로’ 같은 소개 카피, 질문형 도입문, 느낌표 연속, 이모지.
- 제목 위의 작은 영문 대문자 라벨(OVERVIEW, KEY INSIGHT 등).
- 문장마다 굵은 글씨, 모든 항목 앞의 아이콘.
- 원문에 없는 요약 박스(‘핵심 요약’, ‘Key takeaways’)와 성과 수치.

정식 제목, 공식 슬로건, 연사가 준 초록은 고치지 않고 그대로 싣는다. 초록·결론을 쓰지 말라는 규칙으로 확대해석하지 않는다.

**조형**

- 말풍선·대화 버블, 떠다니는 원·블롭, 장식용 원형 배경.
- 알약 모양 태그·버튼의 반복, 큰 모서리 반경 카드로 화면을 채우는 구성, 벤토 그리드.
- 카드마다 다른 파스텔 배경, 보라·분홍 그라데이션, 유리 효과, 그림자·블러.
- 자동 캐러셀, 스크롤 진입 애니메이션, 화면을 가리는 챗봇 캐릭터.
- 허구의 후기, 협력기관 로고 줄, 카운터.

데이터 점, 라디오 버튼, 기능 아이콘, 학술 도식의 노드는 ‘버블’이 아니다. 필요한 곳에 쓴다.

흰 바탕의 GNU Blue는 대비가 3.04:1이다. 24px 이상 또는 굵은 19px 이상 글자, 선, 테두리에만 쓴다. 작은 글자와 흰 글자 버튼에는 동작색을 쓴다. 학과 기존 안내문처럼 GNU Blue 띠에 흰 글자를 얹을 때는 띠 안의 모든 글자를 18pt 이상 굵게 한다. 로고 색을 어둡게 바꿔서 대비를 맞추지 않는다. 데이터 계열은 색과 함께 기호·선 종류로 구분한다.

KRDS의 정부 청색(`#256EF4`)은 대학 색이 아니다. 대학 결과물에 쓰지 않는다.

## 4. 서체

| 매체 | 서체 | 근거 |
|---|---|---|
| 인쇄물 국문 | Noto Sans KR | 공식 BS16 국문 지정서체 |
| 인쇄물 영문 | SUIT | 공식 BS17 영문 지정서체 |
| 웹 본문 | Noto Sans KR | 관찰: 홈페이지 본문 CSS |
| 웹 메뉴·페이지 제목 | SUITE 700–800 | 관찰: 홈페이지 `layout.css` |

SUIT(VI)와 SUITE(홈페이지)는 다른 서체다. 세 서체는 모두 SIL OFL 1.1이며 `assets/fonts/`에 들어 있다. Noto Sans KR은 완성형 한글 11,172자·라틴·그리스 문자·수학 기호로 줄인 사본이다. SUIT와 SUITE는 예약 서체명이 있어 원본 파일을 그대로 넣었다. 빌드한 HTML에는 폰트가 포함되므로 다른 PC에서도 같은 모양으로 열린다. 로고 안의 학교명은 서체로 다시 쓰지 않고 로고 파일을 쓴다.

**크기(제안)**

| 영역 | A4 안내문 | A0 포스터 | 16:9 발표(1280px 기준) | 웹 데스크톱 / 모바일 |
|---|---|---|---|---|
| 제목 | 26–29pt, 700 | 70–80pt | 44–48px | 33px / 28px, 800 (관찰: 1.65rem×20px) |
| 섹션 제목 | 15–17pt | 34–36pt | 36–38px | 24px / 22px |
| 본문 | 11.5–12pt, 행간 1.8 | 24–26pt, 행간 1.6 | 24–26px | 17px, 행간 1.65 (KRDS 본문 토큰 참고) |
| 캡션·출처 | 8.5–10pt | 18–20pt | 16–18px | 14–15px |

한글 제목은 `word-break: keep-all`로 단어 단위 줄바꿈한다. 내용이 넘치면 글자를 줄이기 전에 문장을 다듬거나 쪽을 나눈다.

## 5. 로고와 모티프

`assets/official/`의 원본(AI·PDF·PNG·JPG)은 대학 홈페이지 공개 자료를 변경 없이 보관한 것이다. HTML에는 원본 벡터 경로를 그대로 잘라 낸 `assets/derived/`의 SVG를 쓴다.

| 파일 | 원본 | 용도 |
|---|---|---|
| `gnu-signature.svg` | BS08 국영문 가로조합 | 기본 기관 표시 |
| `gnu-symbol.svg` | BS08 심벌 부분 | 슬라이드 바닥글 같은 작은 자리 |
| `fly-with-gnu.svg` | 공식 안내문 서식의 슬로건 로고타이프 | 서식형 상단, 안내문 하단 왼쪽 |
| `emblem-signature-white.svg` | 공식 안내문 서식의 흰색 엠블럼 조합 | 그라데이션 띠 위 |

- 늘이기, 색 바꾸기, CSS `filter`, 그림자, 외곽선 추가, 생성형 AI로 다시 그리기를 하지 않는다.
- 여러 도안이 함께 있는 견본 시트(BS13, BS14, BS21, BS23)를 통째로 붙이지 않는다. 한 도안만 `scripts/derive_svg.py`로 잘라 쓴다.
- 최소 크기와 보호 공간은 해당 원본 규정을 따른다. 이 문서의 여백값을 공식 보호 공간이라 부르지 않는다.
- FLY WITH GNU는 별도 슬로건 BI다. 요청이 있을 때나 학과 행사 안내문에만 쓴다.

**테두리와 심벌을 잇는 표지.** 공식 BS23 응용형과 학과 발표 표지는 테두리 윗선 위에 GNU 글자가 걸린 구성을 쓴다. 로고를 늘리지 않고 같은 효과를 내려면 시그니처 높이 `H`를 테두리 두께 `B`의 1/0.093배로 하고, 로고 윗변을 테두리 바깥 선보다 `0.035H` 위에 둔다. 심벌 윗변이 테두리와 같은 높이·두께로 이어진다. 로고 왼쪽에는 여백을 두지 않고 오른쪽에만 흰 여백을 둔다. `theme.css`의 `.gap`이 이 계산을 한다.

**색상·꽃 모티프.** 회색·금색·은색 반전 로고는 BS14, GNU 글자 띠는 BS21, 장미·철쭉은 BS23에서 고른다. 꽃 도안은 학과 행사·초청장에 쓰고 연구 그림이나 축 위에 겹치지 않게 한다.

## 6. 캐릭터 지누·누누

지누는 진주에서 발견된 마이크로랍터 발자국에서 따온 대학 공룡 캐릭터이고, 누누는 지누 머리 위의 아기 공룡이다. 원본은 대학 홈페이지의 대학 캐릭터·캐릭터 응용 디자인 페이지에서 받는다(`python3 scripts/assets.py --fetch-character`, 받은 파일은 `assets/character/official/`). 그 페이지의 이용 조건이 이 문서보다 우선한다.

**쓰는 곳(제안)**

| 매체 | 위치 | 크기 |
|---|---|---|
| A4 안내문·세미나 안내 | 하단 오른쪽, 기관 표시 옆. 바닥 선에 발이 닿게 | 높이 30–38mm |
| 서식형 안내문 | 하단 띠 바로 위 오른쪽 | 높이 30–36mm |
| 발표자료 | 표지 또는 마지막 장 오른쪽 아래 | 슬라이드 높이의 20–25% |
| 학과 행사 웹페이지 | 하단 정보 영역 | 높이 80–120px |
| 학술포스터 | 기본으로 넣지 않는다. 학과 행사용이면 하단 기관 표시 옆만 | 높이 60–80mm |

한 쪽에 한 번, 한 자세만 쓴다. 공식 응용 디자인에 있는 표정·자세·단과대학 도안 중에서 고른다.

**하지 않는 것**

- 말풍선을 달거나 대사를 쓰지 않는다. 캐릭터가 학교·연사의 의견을 말하는 것처럼 만들지 않는다.
- 새 표정·자세·옷을 그리거나 생성형 AI로 비슷하게 만들지 않는다. 좌우 반전, 비율 변경, 색 변경, 일부 잘라 쓰기도 하지 않는다.
- 본문·표·그림·로고 위에 겹치지 않는다. 연구 데이터 그림을 캐릭터 그림으로 대신하지 않는다.
- 판매용 상품이나 외부 기관 홍보에 쓰려면 대학 담당 부서와 먼저 협의한다.

캐릭터는 장식이므로 `alt=""`로 넣는다. 캐릭터가 의미를 전달하는 유일한 수단이면 짧은 대체텍스트를 쓴다.

## 7. 매체별 구성

### A4 안내문 (210×297mm)

학과 기존 안내문의 양식을 따른다. 바깥 여백 10mm, 0.5mm GNU Blue 테두리, 위쪽 청색 제목 띠, 흰 본문, 아래쪽 기관 표시.

- **홍보문(띠형)**: 띠에 행사명. 본문에 `주제: / 연사: / 일시: / 장소:` 형식의 항목 목록. 항목명은 동작색 굵게, 값은 본문색. 아래에 추가 안내, 하단에 주최·문의와 시그니처+학과명.
- **세미나 안내**: 띠 첫 줄 왼쪽에 일시·장소(굵게), 오른쪽에 세미나 이름. 다음 줄에 강연 제목, 오른쪽 정렬로 연사 소속·이름. 본문은 초록(양쪽 정렬, 행간 1.8), 참고문헌 목록, 연구비 표기, 문의 순. 하단 왼쪽 FLY WITH GNU(선택), 오른쪽 시그니처+학과명.
- **서식형**: 공식 안내문 서식을 A4 세로로 옮긴 형태. 서식 그라데이션 테두리, 왼쪽 위 테두리 틈의 FLY WITH GNU, 하단 그라데이션 띠의 흰색 엠블럼 조합. 원본 서식은 A3 가로라는 점을 기억한다.

학과명은 시그니처 오른쪽에 같은 바닥선으로, GNU Grey 굵은 글자로 둔다. 로고 그림 안에 합치지 않는다. 사진·QR은 실제 파일이나 주소를 받았을 때만 넣는다. 내용이 한 쪽을 넘으면 두 쪽으로 나눈다.

### A0 학술포스터 (841×1189mm 세로, 학회 규격 우선)

- 바깥 여백 24–26mm. 제목 영역은 2.2mm GNU Blue 테두리 상자, 테두리 윗선에 시그니처를 잇는다(5장).
- 제목 영역: 오른쪽 위에 학회명·세션·발표번호, 제목(영문은 SUIT 500, 핵심어만 800), 부제, 저자(발표자는 GNU Blue 굵게, 소속 번호 위첨자), 소속, 오른쪽 아래에 QR과 ‘발표자 연락처’ 라벨.
- 본문: 2단 기본, 그림이 많으면 3단. 단 사이 16mm. 섹션 제목 아래 1.2mm GNU Blue 선.
- 순서는 연구에 맞춘다. 배경·질문, 방법, 결과, 비교·검증, 논의·한계가 출발점이다.
- 결과 그림을 가장 크게 둔다. 축 이름·단위·범례·표본 수·오차 정의를 캡션에 적는다. 받지 않은 통계량은 쓰지 않는다.
- 하단: 1mm GNU Blue 선, 참고문헌·연구비 표기, 오른쪽에 연락처와 시그니처+학과명.
- 메뉴, 검색창, 버튼, 웹 경로 표시를 넣지 않는다.

### 16:9 HTML 발표자료 (1280×720px 기준)

- 표지: 5.2% 안쪽 여백의 GNU Blue 테두리, 왼쪽 위 테두리 윗선에 시그니처. 제목(핵심어만 굵게), 저자(발표자 GNU Blue), 소속, 오른쪽 아래 QR·연락처.
- 본문: 왼쪽 위 슬라이드 제목, 아래 3px GNU Blue 선. 글과 그림은 한 단 또는 두 단. 바닥글 왼쪽에 작은 심벌과 학과·연구실, 오른쪽에 쪽 번호.
- 한 장에 글 6줄 안팎. 수식·그래프는 벡터로 넣는다.
- 발표 보기: 방향키·PageUp/PageDown 이동, Esc 전체 보기. 인쇄하면 모든 장이 한 장씩 나온다.

### 웹페이지

대학 홈페이지 하위 안내 페이지의 배치에 KRDS 구성 요소를 대응시킨다.

```text
[본문 바로가기]                                  ← KRDS 건너뛰기 링크
시그니처(홈 링크)                 주 메뉴(SUITE 700, 18px)
──────────────────────────────────────────────
페이지 제목(SUITE 800, 33px)      홈 > 상위 메뉴 > 현재 페이지  ← 브레드크럼
──────────────────────────────── (1px #222)
[ 하위 메뉴 | 하위 메뉴 | 하위 메뉴 ]   ← 직사각형 탭(관찰: tab_st1), 선택은 동작색 채움
▌섹션 제목
문단 / 표(윗선 3px, 행 구분선) / 자료 목록
──────────────────────────────────────────────
운영 부서 · 주소 · 연락처 · 최종 수정일          시그니처   ← 회색 면 하단
```

- 폭 최대 1200px, 좌우 24px(제안). 대학 홈페이지 컨테이너는 1565px(관찰). 모바일 좌우 16px, 768px 이하에서 한 단.
- 페이지 이동은 `a`, 화면 안 전환은 `button`. 선택된 메뉴·탭은 `aria-current`. 표는 `caption`과 `scope`.
- 버튼·입력 높이 44px 이상, 모서리 2–4px, 그림자 없음(제안).
- 텍스트 대비 4.5:1, 큰 글자·UI 3:1, 보이는 포커스, 320px 폭과 200% 확대에서 가로 스크롤 없음. KRDS와 한국형 웹 콘텐츠 접근성 지침(KWCAG 2.2)의 검사 항목을 따른다.
- 검색·로그인·언어 선택·공유는 실제로 동작할 때만 둔다.
- KRDS의 ‘공식 전자정부 누리집’ 배너와 정부 상징은 쓰지 않는다. 대학 페이지는 정부 누리집이 아니다.
- 연구실·행사 페이지에 대학 전체 메뉴를 복제하지 않는다. 운영 주체의 실제 메뉴만 둔다.

## 9. 저장과 확인

기본 결과는 편집 가능한 HTML, 같은 내용의 PDF, PNG다. 발표자료는 다쪽 PDF와 장별 PNG, 웹페이지는 전체 PNG와 읽기용 PDF. PPTX·SVG는 요청할 때만 만든다.

`node scripts/export.mjs 입력.html 출력폴더`는 외부 요청, 깨진 그림, 글자 넘침, 종이 밖으로 나간 글자, 로고·캐릭터가 글자를 가리는 경우를 찾아 멈춘다. 실패하면 HTML을 보존하고 실패한 형식과 이유를 그대로 보고한다. 만들지 않은 파일을 만들었다고 말하지 않는다.

마무리 점검:

- 첫 줄이 실제 제목인가. 2장의 표현이 없는가.
- 인명·일정·소속·결과가 모두 원문에 있는가. 빈 항목은 보고했는가.
- 공식색·관찰값·제안값을 섞어 부르지 않았는가. 작은 글자에 GNU Blue를 쓰지 않았는가.
- 로고·캐릭터가 원본 그대로인가. 견본 시트 전체를 붙이지 않았는가.
- 인쇄물: 실물 크기, 폰트, 그림 해상도(배치 크기에서 150–300ppi), 잘림. 대형 포스터는 벡터 PDF로 인쇄한다. CMYK 변환은 인쇄소 프로파일로 하고, 그 결과를 학교 공식색의 새 정의로 취급하지 않는다.
- 웹: 320·768·1360px, 200% 확대, 키보드 이동, 포커스, 색대비.
