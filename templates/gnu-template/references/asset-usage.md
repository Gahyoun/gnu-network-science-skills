# 로고·공식 도안 사용

`assets/official/`은 대학 공개 다운로드에서 받은 로고·VI 원본이다. `.ai`는 Adobe Illustrator 문서이며 인공지능 생성 이미지라는 뜻이 아니다. 일부 파일명은 찾기 쉽게 바꾸었지만 내용은 변경하지 않았다. 원래 파일명·URL·출처·SHA-256은 `assets/manifest.json`에 기록했다.

이 폴더는 학교가 승인한 공식 배포물이라는 의미가 아니다. 로고·모티프·교화 도안의 권리는 원 권리자에게 있다. 저장소의 소프트웨어 라이선스가 학교 자산에 대한 권리나 별도 재배포 허가를 부여하지 않는다. 최신 이용 조건은 [공식 VI 페이지](https://www.gnu.ac.kr/main/cm/cntnts/cntntsView.do?cntntsId=1198&mi=1369)에서 확인한다.

## 자산 선택

- 엠블럼, 국문·영문 조합, 가로·세로 시그니처.
- 전용색상, 색상활용, 지정서체 견본. 지정서체 파일 자체는 포함하지 않는다.
- 그래픽 모티프C, 교화(장미·철쭉)의 기본형·응용형 도안.
- FLY WITH G.N.U의 로고타이프·국문 시그니처.
- 공식 안내문 서식.

지누·캐릭터 원본과 사용자 개인 포스터·스크린샷은 포함하지 않는다.

## 출력

1. `assets/catalog.md`에서 원본을 고른다.
2. 여러 조합이 포함된 보기 시트라면 필요한 완성 도안 하나를 선택한다. 시트 전체를 페이지 로고로 붙이지 않는다.
3. 원본을 보존하고 사본에서 웹용 SVG·PNG 또는 인쇄용 PDF를 내보낸다.
4. 비례·지정색·글자 간격·학교명 조합을 유지한다. 학교명을 일반 텍스트로 다시 조판해 로고로 사용하지 않는다.
5. 공식 최소 크기·보호 공간은 해당 원본 규정에서 확인한다. 예시 템플릿의 여백을 공식 규정으로 표시하지 않는다.
6. SVG는 스크립트·외부 참조 없이 내보내고 원본과 비교한다.

`assets/derived/gnu-signature.svg`는 HTML에서 바로 쓰도록 선택한 국영문 가로형 출력 사본이다. HTML 예시에는 이 SVG를 data URI로 포함해 한 파일만 전달해도 로고가 표시된다. 도안의 권리는 출력 사본에서도 동일하게 유지된다.

기본 실행 `python3 scripts/assets.py`는 오프라인에서 파일 헤더와 SHA-256을 검사한다. `--download`는 명시적으로 요청했을 때 빠진 파일만 가져오며 기존 원본을 덮어쓰지 않는다. 파일 검증은 Illustrator의 모든 레이어·텍스트 편집 가능성을 보장하지 않는다.
