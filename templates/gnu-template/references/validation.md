예시 PNG와 PDF를 렌더링해서 로고·글자·배치를 확인했다. 출력에 사용된 대체 서체는 시스템 한글 산세리프이며, Noto Sans KR·SUIT·SUITE 파일은 패키지에 넣지 않았다. PDF의 약 0.1mm 차이는 Chromium의 페이지 단위 반올림이다.

공식 색상·꽃 모티프는 원본 파일과 선택 지침을 수록했다. 모든 변형을 자동 조합하는 생성기나 학교 승인 도구라는 뜻은 아니다. 예시에는 기본 청색 테마와 선택한 국영문 가로형 로고를 사용했다.

가로 세미나 추가 시 긴 영문 제목과 국문 초록을 넣어 줄바꿈·높이 넘침을 확인했다. `flyer`와 `seminar`의 세로·가로 배치 모두 지정된 A4 높이 안에 들어갔다. 기존 세로형은 기본값으로 유지한다.

사용자 후속 요청을 반영해 웹 기본형의 캠퍼스 항공사진을 제외하고 흰 헤더·짙은 현재 위치 행·직사각형 메뉴·항목별 본문 구성을 확인했다. A4 홍보문·세미나의 세로·가로형은 공식 FLY 도안 기본 포함, `--no-logo`로 전체 로고 생략, `fly_with_gnu: false`로 FLY만 생략되는 것을 확인했다. 네 A4 조합에 선택 이미지를 넣어 이미지 로드, 종이 높이, 본문·푸터·로고 간 겹침을 검사했다. FLY SVG는 PDF 호환 Illustrator 원본의 선택 영역을 렌더링해 비교했다. 수정된 공개 PDF 4개를 다시 렌더링해 배치를 확인했다.
