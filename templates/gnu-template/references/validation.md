# 배포 전 확인 기록

확인일: 2026-10-04. Linux 클라우드 환경, Python 3.11, Node.js 22, Playwright 1.56 Chromium. 패키지에 넣은 Noto Sans KR·SUIT·SUITE로 출력했으므로 서체는 운영체제와 관계없이 같다. 실제 내용을 채운 결과물은 길이가 달라지므로 다시 출력해 확인한다.

## 예시 출력

| 예시 | PDF | PNG |
|---|---|---|
| A4 홍보문 `flyer` | 1쪽, 210×297mm | 794×1123 |
| A4 공식 서식형 `notice-form` | 1쪽, 210×297mm | 794×1123 |
| A4 세미나 안내 `seminar` | 1쪽, 210×297mm | 794×1123 |
| A0 포스터 `poster` | 1쪽, 841×1189mm | 3179×4494 |
| 16:9 발표 `slides` | 6쪽, 1280×720px(960×540pt) | 6장, 각 1280×720 |
| 웹페이지 `web` | 읽기용 A4 1쪽 | 1360×1266 |

모든 PDF에 Noto Sans KR(영문 포스터는 SUIT, 웹은 SUITE 포함) 부분 글꼴이 내장됐다. 출력 중 외부 네트워크 요청은 없었다.

## 검사 항목

| 항목 | 방법 | 결과 |
|---|---|---|
| HTML 특수문자 | 제목에 `<script>`·따옴표·`&` 입력 | 글자로 표시, 실행 코드 없음 |

| 그림이 글자 가림 | 캐릭터를 본문 위로 옮김 | `그림이 글자를 가림(mascot)` 오류 |
| 외부 리소스 | 외부 웹폰트 링크 추가 | 오류로 출력 중단 |

| 키보드 | Tab → 본문 바로가기 → Enter → 탭 메뉴·표·링크 | 순서대로 이동, 포커스 표시 |
| 발표 보기 | 발표 보기 → → → → Esc | 3/6 표시, 한 장만 보임 → 전체 6장 |

| 테두리-심벌 연결 | 포스터·표지 확대 이미지 | 테두리 선이 심벌 윗변과 같은 높이·두께로 이어짐 |

| 배포 ZIP | `package.py`, `package.py --lite` | 전체 103개 15.6MB, 경량 54개 2.9MB, 최상위 `gnu-template/SKILL.md` |
| SKILL.md 앞부분 | name·description 형식 | name 12자, description 246자, 꺾쇠 없음 |

## 확인하지 못한 것

- **캐릭터 원본 수집**: 이 환경에서는 학교 사이트 접속이 막혀 `--fetch-character`를 실제 페이지에 실행하지 못했다. 링크 추출과 파일명 해석은 가짜 HTML·응답 헤더로만 시험했다. 학교 사이트에 접속되는 PC에서 `--dry-run`으로 목록을 먼저 확인한다.
- KRDS·대학 홈페이지의 최신 값은 이번에 다시 열람하지 못했다. 근거는 1차 열람 기록(`source-notes.md`)이다.
- Windows·macOS에서의 `export.mjs` 재실행, Claude 웹앱 스킬 업로드는 이번에 시험하지 않았다.
- PDF는 RGB다. 인쇄소의 CMYK·별색 변환은 대신하지 않는다.
