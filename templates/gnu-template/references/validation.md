# 배포 전 확인 기록

확인일: 2026-10-04. Linux 클라우드 환경, Python 3.11, Node.js 22, Playwright 1.56 Chromium. 패키지에 넣은 Noto Sans KR·SUIT·SUITE로 출력했으므로 서체는 운영체제와 관계없이 같다. 실제 내용을 채운 결과물은 길이가 달라지므로 다시 출력해 확인한다.

main 브랜치의 가로 세미나·FLY 기본 배치·웹 VI 하위 페이지형 작업(macOS, Playwright 1.62.1에서 확인)을 이 빌더로 옮긴 뒤 아래 항목을 다시 확인했다.

## 확인하지 못한 것

- **캐릭터 원본 수집**: 이 환경에서는 학교 사이트 접속이 막혀 `--fetch-character`를 실제 페이지에 실행하지 못했다. 링크 추출과 파일명 해석은 가짜 HTML·응답 헤더로만 시험했다. 캐릭터 자리는 공식 장미 도안(BS23)을 대체 그림으로 넣어 시험했다. 학교 사이트에 접속되는 PC에서 `--dry-run`으로 목록을 먼저 확인한다.
- KRDS·대학 홈페이지의 최신 값은 이 환경에서 다시 열람하지 못했다. 근거는 `source-notes.md`의 열람 기록이다.
- Windows·macOS에서의 `export.mjs` 재실행, Claude 웹앱 스킬 업로드는 이번에 시험하지 않았다.
- PDF는 RGB다. 인쇄소의 CMYK·별색 변환은 대신하지 않는다.
