# 매체별 요청문

스킬로 설치했다면 Claude Code는 `/gnu-template`, Codex는 `$gnu-template`으로 시작한다. 스킬이 없는 AI에는 `DESIGN.md`와 가장 가까운 `examples/*.html`을 첨부하고 “첨부한 DESIGN.md를 적용해 …”로 시작한다. 대괄호는 실제 내용으로 바꾼다. 모르는 항목은 비워 두라고 적는다.

## A4 홍보문

```text
GNU template으로 A4 홍보문을 만들어 주세요. HTML·PDF·PNG로 저장해 주세요.
제목: [행사명]
주제: [주제]
연사: [소속 · 이름 직함]
일시: [연월일(요일) 시각]
장소: [건물-호실]
추가 안내: [원문, 없으면 생략]
주최·문의: [학과 · 담당자 · 연락처]
하단 학과명: [학과명]
없는 정보는 만들지 말고 [입력 항목]으로 남겨 주세요.
```

## 세미나 안내(초록 포함)

```text
GNU template의 세미나 안내 양식으로 만들어 주세요.
띠 첫 줄: [일시, 장소] / 오른쪽: [학과·연구소 세미나 이름]
강연 제목: [원문 제목]
연사: [소속 · 이름 직함]
초록: [원문 그대로]
참고문헌: [목록]
연구비 표기: [원문, 없으면 생략]
문의: [담당자 (이메일)]
하단 왼쪽 FLY WITH GNU 사용, 오른쪽 시그니처 옆 학과명: [학과명]
초록은 고치지 말고 넘치면 두 쪽으로 나눠 주세요.
```

## 공식 서식형 안내문

```text
GNU template의 공식 안내문 서식형(style: form)으로 A4 안내문을 만들어 주세요.
제목·항목·세부 안내: [원문]
주관 부서·문의: [정보]
```

## 학술포스터

```text
GNU template으로 학술포스터를 만들어 주세요.
규격: [학회 규격, 없으면 A0 세로]
언어: [영어 / 한국어]
학회·세션·발표번호: [정보]
제목: [제목, 강조할 핵심어는 **로 표시]
저자: [이름, 소속 번호, 발표자 표시]
소속: [번호별 소속]
본문·그림·수식·참고문헌·연구비 표기: [원문과 그림 파일]
QR: [QR 이미지 파일 또는 생략]
제목 상자 윗선에 학교 시그니처를 잇고, 결과 그림을 가장 크게 배치해 주세요.
데이터·결론·지원기관을 새로 만들지 마세요. 축·단위·범례가 빠졌으면 알려 주세요.
```

## 발표자료

```text
GNU template으로 16:9 HTML 발표자료를 만들어 주세요.
제목·발표자·공동저자·소속: [정보]
발표 시간과 청중: [정보]
원고·그림·수식: [첨부]
표지는 테두리 윗선에 학교 시그니처, 본문은 제목 아래 청색 선과 바닥글 심벌로 해 주세요.
한 장의 글은 6줄 안팎. HTML, 다쪽 PDF, 장별 PNG로 저장해 주세요.
```

## 웹페이지

```text
GNU template으로 [연구실 / 학술행사 / 자료실] 웹페이지를 만들어 주세요.
페이지 제목·운영 주체·경로(홈 > …): [정보]
하위 메뉴와 각 내용: [실제 콘텐츠]
일정표·자료 링크·문의·주소·수정일: [정보]
대학 홈페이지 하위 페이지처럼 제목, 현재 위치, 직사각형 탭, 표로 구성해 주세요.
동작하지 않는 검색·로그인 버튼은 넣지 말고 320px 폭, 200% 확대, 키보드 이동을 확인해 주세요.
```

## 지누 넣기

```text
assets/character/official/의 공식 지누 원본에서 [기본형 / 지정한 자세] 하나를 골라
안내문 오른쪽 아래(시그니처 옆)에 넣어 주세요. 말풍선·대사·반전·색 변경 없이,
본문과 겹치지 않게 해 주세요. 원본이 없으면 scripts/assets.py --fetch-character 실행을 안내해 주세요.
```

## 색·꽃 모티프

```text
기본 구성에 [회색 반전 로고 / 모티프C 띠 / 장미 응용형 / 철쭉 응용형]을 적용해 주세요.
assets/catalog.md와 references/brand-variants.md에서 공식 도안 하나를 골라 비례와 색을 유지하고,
본문·그림을 가리지 않게 배치해 주세요.
```
