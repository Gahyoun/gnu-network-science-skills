# 매체별 요청문

설치한 스킬은 Claude Code에서 `/gnu-template`, Codex에서 `$gnu-template`으로 호출한다. 다른 AI에서는 ‘첨부한 DESIGN.md와 예시 HTML을 적용해 …’로 시작한다. 아래 대괄호를 실제 내용으로 바꾼다.

## A4 홍보문

```text
GNU template으로 아래 행사 안내를 A4 세로 HTML 홍보문으로 만들어 주세요.
제목: [행사명]
주제: [주제]
연사: [이름·소속]
일시와 장소: [실제 정보]
대상과 참여 방법: [실제 정보]
주최와 문의: [실제 정보]
추가 안내: [원문]
흰 바탕, 청색 제목 띠와 직사각형 테두리, 하단 학교 로고를 사용하세요.
HTML, PDF, PNG로 저장하고 A4 크기와 잘림을 확인해 주세요.
```

## 세미나 초록 안내

```text
GNU template으로 첨부 초록을 A4 세미나 안내문으로 만들어 주세요.
상단에 일시·행사명·강연 제목·연사를, 본문에 제공한 초록과 참고문헌을 배치하세요.
하단에 실제 장소·주최·문의처와 학교 로고를 넣어 주세요.
[행사 정보와 초록 원문]
HTML, PDF, PNG로 저장하고 내용이 길면 읽기 쉬운 두 쪽으로 구성하세요.
```

## 학술포스터

```text
GNU template으로 첨부 연구 내용을 학술포스터로 만들어 주세요.
규격: [학회 규격 / 없으면 A0 세로]
언어: [한국어 / 영어 / 병기]
제목·저자·소속: [실제 정보]
본문·그림·표·수식·참고문헌: [원문과 파일]
연구 데이터·결론·지원기관을 새로 만들지 마세요.
2단 또는 3단을 내용에 맞게 선택하고 축·단위·범례·캡션을 확인하세요.
HTML, 실물 크기 PDF, 미리보기 PNG로 저장해 주세요.
```

## 프레젠테이션

```text
GNU template으로 아래 발표 원고를 16:9 HTML 프레젠테이션으로 만들어 주세요.
발표 제목·발표자·소속: [실제 정보]
예상 시간과 청중: [정보]
원고·그림·수식: [첨부]
흰 바탕과 청색 선, 학교 로고를 사용하고 한 장에 읽을 수 있는 양을 배치하세요.
자동 후크·버블·장식 카드는 넣지 마세요.
편집 가능한 HTML, 하나의 다쪽 PDF, 슬라이드별 PNG로 저장해 주세요.
```

## 간단한 웹페이지

```text
GNU template으로 [연구실 / 행사 / 학과 자료실]의 간단한 웹페이지를 만들어 주세요.
페이지명과 운영 주체: [정보]
본문과 메뉴: [실제 콘텐츠]
일정·자료 링크·문의: [정보]
기존 프로젝트가 있다면 환경: [경로와 프레임워크]
학교 정보 안내 페이지처럼 제목·문단·일정표·자료 목록을 구성하세요.
실제 기능과 콘텐츠를 유지하고 동작하지 않는 검색·신청 버튼을 넣지 마세요.
320px 폭, 200% 확대, 키보드 이동을 확인하세요.
HTML, 전체 화면 PNG, 읽기용 PDF로 저장해 주세요.
```

## 색상과 꽃 모티프 선택

```text
기본 구성에 [회색 / 공식 색상활용 도안 / 모티프C / 공식 장미 프레임 / 공식 철쭉 프레임]을 적용해 주세요.
assets/catalog.md와 references/brand-variants.md에서 공식 완성 도안을 선택하세요.
로고·꽃의 비례와 지정색을 유지하고 본문이나 그림을 가리지 않도록 배치하세요.
```

지누와 캐릭터는 모든 제작물에서 제외한다. 로고·모티프를 쓰려면 해당 원본 파일에도 접근할 수 있어야 한다. 기본 출력은 언제나 HTML·PDF·PNG이며 실제로 실패한 형식은 실패 이유를 보고한다.
