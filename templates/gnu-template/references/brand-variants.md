# 공식 색상 활용과 그래픽 모티프

[학교 VI 기본요소](https://www.gnu.ac.kr/main/cm/cntnts/cntntsView.do?cntntsId=1198&mi=1369)의 아래 원본을 사용할 수 있다. 기본 템플릿은 흰 바탕과 청색 선·제목 띠이며, 다른 변형은 사용자 요청과 매체에 맞춰 선택한다.

| 요청 | 선택할 원본 | 적용 |
|---|---|---|
| 흰 바탕의 청색·회색 로고 | BS08 시그니처, 엠블럼 조합 | 제목 주변 또는 하단 기관 표시 |
| 청색·회색 바탕의 반전 로고 | BS14 색상활용 | 원본에 제공된 해당 조합을 선택 |
| 금색·은색 표현 | BS14 색상활용, BS13 전용색상 | 공식 변형·인쇄 방식을 확인해 적용 |
| GNU를 포함한 띠·색면 | BS21 그래픽 모티프C | 제공된 완성 도안의 비례를 유지 |
| 장미를 포함한 프레임 | BS23 그래픽 모티프E-교화 | 공식 응용형 전체 또는 지정 기본형을 선택 |
| 철쭉을 포함한 프레임 | BS23 그래픽 모티프E-교화 | 공식 응용형 전체 또는 지정 기본형을 선택 |

단순한 색상 선택과 공식 도안 사용을 구분한다. 로고를 CSS `filter`·임의 채색·생성형 재묘사로 바꾸지 않는다. 도안에 없는 새 GNU 프레임을 로고의 획을 늘려 만들지 않는다. 공식 프레임을 배경으로 사용할 때 도안의 종횡비를 유지하고 콘텐츠를 그 안의 여백에 맞춘다. 임의 비율로 늘려 포스터 전체를 채우지 않는다.

꽃 모티프는 학술포스터의 기본 장식이 아니다. 학과 행사·초청장·교내 홍보물에서 요청받으면 적용할 수 있다. 데이터 그림·축·캡션 위에 꽃 도안이 겹치지 않도록 한다. 꽃 원본의 지정색은 테마 색상 변경 기능으로 바꾸지 않는다.

BS14의 청색·회색·금색·은색 조합은 원본 이미지가 포함된 보기 시트다. 여러 변형이 한 파일에 들어 있으므로 완성 도안 하나만 선택해서 내보낸다. 공식 페이지에 예시가 없는 색상 적용은 해당 관리부서와 협의하도록 안내되어 있다.

HTML용 로고 사본 4종과 만드는 방법은 [자산 사용](asset-usage.md)에 있다. 꽃·모티프 도안 하나가 필요하면 같은 방법(`scripts/derive_svg.py --source … --crop …`)으로 원본 AI에서 잘라 쓴다.

## 테두리에 걸린 GNU

BS23 응용형은 GNU 글자가 사각 테두리 윗선에 걸린 프레임을 쓴다. 이 템플릿의 발표 표지·포스터 제목 상자는 로고를 늘리지 않고 같은 인상을 내도록, BS08 시그니처의 심벌 윗변을 테두리 선과 같은 높이·두께로 맞춘다(`theme.css`의 `.gap`, 계산은 DESIGN.md 5장). 꽃이 들어간 공식 응용형 프레임 자체가 필요하면 BS23 원본을 쓴다.
